# [The Glutton's Gate/탐식의 문지기]

> 기존 Java 객체지향 턴제 전투 엔진에 **TRPG식 스토리 분기와 주사위(Dice) 판정**을 결합한 텍스트 기반(CLI) 롤플레잉 게임

---

## 1. 프로젝트 개요

단순 반복형 콘솔 전투에서 벗어나, 플레이어의 **선택지, 캐릭터 스탯, 주사위 판정 결과**가 서사와 전투 양상에 직접 영향을 미치는 텍스트 기반 TRPG입니다.  
2주 개발 기간 내에 안정적인 완성도를 확보하기 위해 GUI 대신 터미널(CLI) 환경에 집중하고, `if-else` 하드코딩이 아닌 **객체 참조 기반 스토리 분기 구조**와 **상속·오버라이딩 기반 전투 시스템**으로 설계했습니다.

* **실행 환경:** Only Java (Console / CLI)

## 4. 핵심 기능

1. **객체 기반 TRPG 스토리 분기 (`StoryNode` / `Choice`)**
   * 장면(Node)과 선택지(Choice)를 객체 인스턴스로 구성하여 분기 흐름을 유연하게 관리
   * 분기 폭발을 방지하기 위해 주요 거점에서 다시 합류하는 **수렴형(다이아몬드) 구조** 채택 (총 7~8개 노드, 전투 2회, 엔딩 2종)
2. **주사위 및 스탯 기반 확률 판정 (`DiceSystem`)**
   * 판정 공식: `주사위 난수(1~20) + 직업 주 스탯 보정치 >= 목표 난이도`
   * `Warrior`(힘 기반 돌파·위협), `Magician`(지능 기반 해독·마법 해제) 등 직업별 강점이 분기에 반영
3. **기존 턴제 전투 엔진과의 유기적 연동**
   * 기존 상속·오버라이딩 구조(`Warrior`, `Magician`의 `castSpell`, `Monster`, `Gameplay`)를 스토리 노드에 통합
   * 대화·탐색 판정 결과가 실제 전투 조건(강제 전투 돌입, 선제공격권 획득, 회복 아이템 확보 등)으로 이어짐

## 5. 스토리 진행 흐름

```text
[1. 도입 노드: 직업 선택 및 사건 발단]
                 │
[2. 탐색 분기 노드: 선택지 + 주사위/스탯 판정]
        ├─ (성공) → [3-A. 지름길 노드: 회복 아이템 또는 버프 획득]
        └─ (실패) → [3-B. 매복 노드: 일반 몬스터와 강제 턴제 전투]
                 │  (두 경로 모두 다음 거점으로 수렴)
                 ▼
[4. 중간 정비 노드: NPC 대화 및 스탯/상태 점검]
                 │
[5. 보스 전초 노드: 기습·협상 주사위 판정]
        ├─ (성공) → 보스전 유리 조건(선공권/약화) 획득
        └─ (실패) → 페널티 상태로 보스전 돌입
                 │
                 ▼
[6. 최종 보스 턴제 전투] ──→ (승리: 해피/히든 엔딩 | 패배: 배드 엔딩)
