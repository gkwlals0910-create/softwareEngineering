# 🍽️ 탐식의 문지기 (The Glutton's Gate)

> **"살아서 나가고 싶다면, 나를 만족시킬 한 끼를 바쳐라."**  
> 순수 Java 터미널(CLI) 환경에서 즐기는 다크 판타지 생존·요리 텍스트 TRPG

---

## 1. 프로젝트 개요

단순 반복형 콘솔 전투에서 벗어나, **캐릭터의 스탯·주사위 판정·탐험 중 확보한 식재료**가 전투와 최종 엔딩에 직접 영향을 미치는 텍스트 기반 TRPG입니다.  
2주 개발 기간 내에 높은 완성도를 확보하기 위해 GUI와 복잡한 장비 시스템을 덜어내고, **터미널(CLI) 가독성**과 **객체지향 기반의 프론트·백엔드 역할 분리**에 집중했습니다.

- **실행 환경:** Only Java (Console / CLI)
- **핵심 컨셉:** 무너진 고대 미궁에 갇힌 모험가가 출구를 막아선 '탐식의 문지기'를 만족시킬 요리를 만들기 위해 괴물을 사냥하고 기이한 식재료를 모으는 생존 탐험

---

## 4. 핵심 기능

### 1) 3직업 & 4스탯 기반 주사위 캐릭터 생성
- **직업:** 전사(`STR +2`), 마법사(`INT +2`), 사냥꾼(`DEX +2`) 중 선택
- **4대 스탯 활용:** 전투뿐만 아니라 비전투 채집·함정 및 최종 요리 판정까지 모든 스탯이 실질적으로 쓰이도록 설계
  - `STR(힘)`: 물리 공격력 / 힘 기반 채집 판정
  - `DEX(민첩)`: 회피·명중 보정 / 함정 돌파 판정
  - `INT(지능)`: 마법 공격력·최대 MP / 독버섯 감별 판정
  - `LUK(행운)`: 치명타 확률 / 희귀 이벤트 및 **최종 요리 판정 보정**

### 2) 랜덤 이벤트 풀(Pool) 기반 탐험 루프
- **전투 이벤트 4종(메인 식재료):** 동굴 슬라임, 고블린 도축업자, 맹독 동굴 지네, 화염 도마뱀
- **비전투 이벤트 4종(보조 식재료·함정):** 기이한 버섯 군락(`INT`), 무너진 저장고 함정(`DEX`), 얼어붙은 보급 상자(`STR`), 탐식의 제단(`LUK`)
- 매 플레이마다 8개 이벤트 풀에서 중복 없이 **4~5회 무작위 진행**하여 리플레이성 확보

### 3) 직관적인 CLI 프론트엔드 UX
- **일반 상태창:** 이름, 직업, HP/MP 바, 4대 스탯, 현재 확보한 요리 재료 목록을 상시 확인
- **컴팩트 턴별 전투 상태창:** 스크롤 가독성을 해치지 않도록 매 턴 피아 체력바와 핵심 스탯만 압축 출력
- **주사위 판정 연출:** 주사위 굴림 연출과 함께 `주사위 + 보정치 = 합계 (목표치) -> 성공/실패`를 시각적으로 강조

### 4) 식재료 미식 점수 + 최종 요리 주사위 엔딩
- 확보한 식재료의 등급별 점수(일반 1점 / 고급 2점 / 희귀 3점)와 마지막 요리 주사위 결과를 합산해 3가지 엔딩으로 분기

## 5. 게임 진행 흐름

```text
[1. 타이틀 화면 (TitleScene)]
      └─ 던전 입장하기 / 나가기
                 │
                 ▼
[2. 프롤로그 & 캐릭터 생성 (CharacterCreateScene)]
      └─ 3줄 프롤로그 → 직업 선택 → 이름/성별 입력 → 주사위 초기 스탯 결정
                 │
                 ▼
[3. 도입 스토리 (StoryScene)]
      └─ 1층 회랑 진입, 선배 모험가의 수첩에서 탈출 규칙(요리 헌납) 확인
                 │
                 ▼
[4. 던전 탐험 루프 (4~5회 반복)]
      ├─ (전투 이벤트) → [CombatScene] 턴제 전투 승리 시 메인 식재료 획득
      └─ (비전투 이벤트) → 도전(스탯 주사위 판정) 또는 우회 선택
                 │
                 ▼
[5. 최후의 식탁 & 엔딩 (StoryScene)]
      └─ 확보한 재료 점수 + 마지막 요리 주사위 판정
            ├─ 18점 이상 : 진 엔딩 (미식의 경지 — 보물과 함께 탈출)
            ├─ 12~17점   : 노말 엔딩 (간신히 합격 — 목숨만 건져 탈출)
            └─ 11점 이하 : 배드 엔딩 (최악의 괴식 — 문지기에게 잡아먹힘)
